# Entre Bandeiras Shoop

Uma loja de camisetas exclusivas online desenvolvida com HTML, CSS e JavaScript puro.

## 🎯 Descrição

Entre Bandeiras Shoop é um e-commerce moderno e responsivo focado na venda de camisetas exclusivas para torcedores. O projeto oferece uma experiência de compra completa com catálogo de produtos, carrinho de compras persistente e formulário de contato.

## ✨ Funcionalidades

- ✅ Catálogo de produtos com imagens e descrições
- ✅ Carrinho de compras com persistência (localStorage)
- ✅ Adição e remoção de produtos
- ✅ Atualização de quantidade de itens
- ✅ Cálculo automático de totais
- ✅ Formulário de contato funcional
- ✅ Design responsivo (Mobile, Tablet, Desktop)
- ✅ Suporte a modo escuro
- ✅ Animações suaves
- ✅ Acessibilidade (ARIA labels, alt text)

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Styling responsivo, gradientes, animações
- **JavaScript (Vanilla)** - Lógica do carrinho e interatividade
- **LocalStorage** - Persistência de dados do carrinho

## 🚀 Como Usar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/fotoslepiqueyas-del/entre-bandeiras-shoop.git
   ```

2. **Acesse o diretório**
   ```bash
   cd entre-bandeiras-shoop
   ```

3. **Abra no navegador**

   - Ou use um servidor local (Live Server, Python, etc.)

## 💡 Funcionalidades Detalhadas

### Catálogo de Produtos
- Exibição em grid responsivo
- Imagens com placeholders
- Descrição e preço de cada produto
- Botão "Adicionar ao Carrinho"

### Carrinho de Compras
- Adicionar produtos dinamicamente
- Modificar quantidade
- Remover itens
- Total automático
- Persistência com localStorage
- Notificações visuais

### Contato
- Formulário com validação básica
- Campos: Nome, Email, Mensagem
- Feedback ao enviar

## 🎨 Design

- Cores: Vermelho (#d60000), Preto, Branco, Gradientes
- Fonte: Segoe UI, Tahoma, Geneva, Verdana
- Layout: CSS Grid e Flexbox
- Responsividade: Mobile-first approach

## 📱 Responsividade

- **Desktop**: Layout completo com grid 3+ colunas
- **Tablet**: Layout ajustado com 2 colunas
- **Mobile**: Layout single column, navegação adaptada
